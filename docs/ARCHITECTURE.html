2 · 库 crate 模块地图

src/ 的模块划分为门面/状态层与四个核心子系统。词汇（块类型、块标志、extra 类型、压缩方法名）集中在 rar50/mod.rs，结构（序列化/解析）在 rar50/headers.rs——两者拆分使常量保持无依赖、头代码可用 crate 其余部分。

门面 & 状态（顶层）

  • lib.rs — 门面 RarArchive + 再导出
  • archive.rs — RarArchive 共享状态 + 生命周期
  • rewrite.rs — 手术式 delete/rename（字节级重写）
  • name_policy.rs — 路径收集 + 掩码
  • version.rs — ArchiveVersion（RAR5/RAR7 检测）
  • features.rs — FeatureSet（能力报告）
  • options.rs — CreateOptions / ExtractOptions
  • error.rs — RarError / RarResult
  • write_progress.rs — 进度回调管线
  • io_util.rs — 原子暂存 + 有界读取
  • parallel.rs — parallel 特性的 Rayon 池
  • detect.rs — 签名 / SFX 扫描

容器层 · rar50/

  • mod.rs — 常量 + 块/头标志词汇
  • headers.rs — 块 & 头数据结构（序列化/解析）
  • vint.rs — 变长整数 codec
  • blake2sp.rs — BLAKE2sp 成员哈希
  • extract.rs — 读路径：scan/list/read/extract/solid 链
  • write/mod.rs — writer 门面：create/add/close 管线
  • write/engine.rs — payload/CBC 发射机
  • write/layout.rs — 字典定尺 + STORE 回退探测

压缩 codec · codec/

  • mod.rs — 分发
  • rar50.rs — LZSS+Huffman 编码 + 解码
  • bitstream.rs — MSB-first 位 I/O
  • huffman.rs — Huffman 表构建/解码（quick-lookup）
  • filters.rs — Delta / E8 / E8E9 / ARM 过滤器
  • match_finder.rs — BT4 匹配查找
  • window.rs — 共享 LZ 窗口（solid 链）

加密层 · crypto/

  • mod.rs — 解密辅助
  • rar50.rs — AES-256-CBC + KDF + hash-key MAC

恢复层 · recovery/

  • mod.rs — repair/rebuild 分发
  • rar5.rs — 内联恢复记录（RR）
  • rev5.rs — 恢复卷（.rev, REV5）
💡 写路径（rar50/write/*）增量发射块：engine.rs 处理 payload +（可选）CBC 发射，layout.rs 决定字典大小并探测 STORE 回退。rewrite.rs 是手术路径：delete/rename 字节级复制保留的文件块、仅重发射变更的块，丢弃内联恢复记录并重建 quick-open 记录。

3 · 设计笔记

有界内存（Bounded memory）

大成员（磁盘） → STORE 流式 · 压缩：4 MiB 分块 + 共享 LZ 窗口 → 提取流式写出（不物化整文件）

压缩本身把 LZSS 流切成 ≤ 128 KiB（MAX_BLOCK_SIZE）块，每块独立 Huffman 表；过滤器区域上限 0x3FFFF。最坏内存 ≈ packed 大小 + 一个块，而非正比于整个文件的符号表。

安全提取（Safe extraction，默认开启）

名字清洗（拒绝 ../ · 绝对路径 · 盘符 · NUL） → 路径在目标内 → 单文件 / 总大小上限 → 临时兄弟 + 完整性校验后 rename

加密成员验证 MAC'd 校验和，损坏密文必被检出。仅对可信归档才放宽这些默认。

Solid 链 & 多线程（互斥）

Solid（串行）

连续压缩成员共享一个 LZ 窗口（更好比率）；保持串行以维持窗口链。

-mt（并行）

多线程压缩；每个线程独立窗口。与 solid 互斥。

Quick-open & 取消

open_quick → 只读 主头 + QO 记录 → listing 为 O(QO) 而非 O(archive)

rar-rs 缓存每个成员（WinRAR 默认只缓存大文件）。长任务通过共享 AtomicBool 协作取消：下一检查点返回 RarError::Cancelled。

流式修复（Streaming repair）

repair_archive_path 在磁盘上修复受损归档，内存中仅持有恢复数据（非整个归档），故可修复极大归档；repair_archive（内存版）在需要时缓冲前缀。
